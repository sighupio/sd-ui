# SIGHUP Distribution UI Release v0.1.0

Welcome to the first release of the SIGHUP Distribution UI, maintained by team SIGHUP.

This release packages [Headlamp](https://headlamp.dev) together with a set of SIGHUP
Distribution plugins into a single container image, providing a web interface for SD clusters.
It is the first tagged build, so `registry.sighup.io/fury/sd-ui` is published from this tag
onwards.

## Image 🚢

| Component  | Version                                                                         | Previous Version |
| ---------- | ------------------------------------------------------------------------------- | ---------------- |
| `sd-ui`    | `v0.1.0`                                                                          | First release    |
| `headlamp` | [`v0.40.1`](https://github.com/kubernetes-sigs/headlamp/releases/tag/v0.40.1)    | First release    |

## Included plugins

| Plugin                     | Version  | Description                                                                                |
| -------------------------- | -------- | ------------------------------------------------------------------------------------------ |
| `sd-core`                  | `0.1.0`  | Cluster landing page with distribution version, module status and resource usage charts.    |
| `sd-alerts`                | `0.1.0`  | Prometheus alerts grouped by rule group, with labels, graph queries and runbook links.      |
| `sd-certificates`          | `0.1.0`  | X.509 certificate expiry tracking via the `x509_cert_not_after` Prometheus metric.           |
| `sd-events`                | `0.1.0`  | Historical Kubernetes events from Loki or OpenSearch.                                       |
| `sd-logs`                  | `0.1.0`  | Log viewer with Loki and OpenSearch backends.                                                |
| `sd-backups`               | `0.1.0`  | Velero backup, restore and schedule dashboard.                                               |
| `sd-policy`                | `0.1.0`  | Policy violations from Kyverno PolicyReports or Gatekeeper constraint status.                |
| `sd-loki-links`            | `0.1.0`  | "View Logs" links on workload detail pages, to Grafana Explore or OpenSearch Dashboards.     |
| `sd-prometheus-autoconfig` | `0.1.0`  | Auto-configures the Headlamp Prometheus plugin address. No UI.                               |
| `headlamp-reevo-theme`     | `0.1.0`  | Custom dark theme.                                                                           |

The upstream [`cert-manager`](https://github.com/headlamp-k8s/plugins) plugin `0.1.0` is also
bundled in the image.

## Notable changes

- All tenant-scoped pages work behind Capsule Proxy, filtering to the namespaces the user can
  access. Pages showing cluster-wide data are marked with an "Unrestricted cluster-wide view"
  indicator.
- Plugins detect which distribution modules are enabled by reading the `furyctl-config`
  secret, and hide the panels that do not apply to the cluster.
- Events and logs support both Loki and OpenSearch, selected from the cluster's logging
  configuration.

## Deployment

The Kubernetes manifests that deploy this image are not part of this repository. They live in
the `ui` module of [`module-utilities`](https://github.com/sighupio/module-utilities), which
also ships the authentication overlays.

## Known issues

- The `ui` module's base package references `registry.sighup.io/fury/sd-ui:latest`. The `latest`
  tag is published from stable tags only, so it resolves for the first time with this release.
